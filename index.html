NS-3: Şəbəkə Simulyasiyasının Mühərriki

Real şəbəkə qurulmadan əvvəl protokolları virtual mühitdə 100% dəqiqliklə test edən diskret hadisə simulyatoru.

↓ Aşağı Sürüşdürün ↓
Komponent 01

Node (Kompüter / Düyün)

Şəbəkədəki hər bir virtual cihaz — kompüter, server və ya marşrutlayıcı (router). C++ kodunda NodeContainer vasitəsilə yaddaşda yaradılır və üzərinə TCP/IP steki quraşdırılır.

Komponent 02

NetDevice (Şəbəkə Kartı)

Cihazları fiziki kanala (Channel) qoşan virtual interfeys. Ethernet, Wi-Fi, 5G və ya Point-to-Point ötürücü kartların riyazi və fiziki davranışını modelləşdirir.

Bölmə 03

Trafikin Yaranması

• Klient (Node 0): 10.1.1.1
• Server (Node 1): 10.1.1.2
• Kanal Sürəti: 5 Mbps | Gecikmə: 2 ms
• Protokol: UDP Echo (Port 9)

Point-to-Point Paket Axını

Şəbəkədə məlumatın necə axdığı və NS-3-ün real TCP/UDP protokollarını necə simulyasiya etdiyi izah olunur. Hər bir enerji sferası 1024 baytlıq real şəbəkə paketini təmsil edir.

İdarəetmə və Analiz

Mükəmməl idarəetmə: NS-3 qrafik interfeyslə yox, birbaşa kodla idarə olunur. NS-3 trafiki yaradan mühərrik (Kinostudiya), Wireshark isə onu oxuyan mikroskopdur (Televizor).

kali@kali: ~/ns-3.40/scratch/demo-test.cc (Kinostudiya) 
NodeContainer nodes;
nodes.Create (2);

PointToPointHelper pointToPoint;
pointToPoint.SetDeviceAttribute ("DataRate", StringValue ("5Mbps"));
pointToPoint.SetChannelAttribute ("Delay", StringValue ("2ms"));

NetDeviceContainer devices = pointToPoint.Install (nodes);
InternetStackHelper stack;
stack.Install (nodes);

Ipv4AddressHelper address;
address.SetBase ("10.1.1.0", "255.255.255.0");
Ipv4InterfaceContainer interfaces = address.Assign (devices);

UdpEchoServerHelper echoServer (9);
UdpEchoClientHelper echoClient (interfaces.GetAddress (1), 9);
pointToPoint.EnablePcapAll ("demo-test");

Simulator::Run ();

Kritik İnfrastruktur

🛡️ Kibertəhlükəsizlik və DDoS

Real dövlət və ya bank şəbəkələrinin 1:1 virtual kopyasında DDoS hücumlarının, botnetlərin və IDS/IPS müdafiə sistemlərinin sıfır risklə test edilməsi.

Telekommunikasiya

📡 5G/6G Mobil Şəbəkələr

Sürətlə hərəkət edən qatarda siqnalın baza stansiyaları arasında qırılmadan ötürülməsi (Handover). Ericsson və Nokia yeni nəsil antenaları NS-3-də sınaqdan keçirir.

Avtonom Nəqliyyat

🚗 Ağıllı Avtomobillər (VANET)

Sürücüsüz avtomobillərin qəzaların qarşısını almaq üçün saniyənin mində biri sürəti ilə bir-biriylə məlumat mübadiləsi (V2V) aparmasının modelləşdirilməsi.

Aerokosmik Rabitə

🛰️ Kosmik və Peyk Şəbəkələri

Starlink kimi meqa-konstellasiyalarda yer kürəsi ilə kosmos arasındakı gecikmələrin (latency) və siqnal itkilərinin dəqiq hesablanması.

Smart City

🏙️ Əşyaların İnterneti (IoT)

Minlərlə şəhər sensorunun LoRaWAN və Zigbee protokolları ilə eyni anda mərkəzə məlumat göndərməsi, batareya ömrü və bina maneələrinin analizi.

Akustik Dalğalar

🌊 Sualtı Rabitə Şəbəkələri

Sualtı qayıqlar və dənizaltı tədqiqat dronları arasında radio dalğaları əvəzinə səs dalğaları ilə qurulan rabitədə duzluluq və temperaturun təsiri.
