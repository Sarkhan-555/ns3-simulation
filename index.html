01

Node və NetDevice

Node şəbəkədəki cihazı təmsil edir: host, router, server. NetDevice onu fiziki kanala bağlayır və paketlərin göndərilməsini idarə edir.

  • NodeProtokol yığını, interfeyslər, yaddaş
  • NetDeviceGöndərmə, qəbul, növbə idarəsi
  • Channelİki cihaz arasında ötürmə mühiti
02

Point-to-Point trafik

İki node arasında Point-to-Point kanal qurulur. Paketlər kanal boyunca hərəkət edir, NS-3 isə gecikmə, itki və ötürmə qabiliyyətini ölçür.
